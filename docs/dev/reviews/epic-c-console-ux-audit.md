## Not verified

- **Reload vs `beforeunload`:** on eval `done` the page reloads after 1400 ms (`dashboard.html:1560`), but the lock and its `beforeunload` guard are released only on `_closed` (`:1518`). If `_closed` arrives after 1400 ms, the user would get a "Leave site?" prompt. The event timing was not observed.
- **Esc key:** `dashboard.html:1270` closes the detail panel on any Esc. Whether one Esc also closes an open help or assistant modal (closing both at once) depends on `static/help-modal.js` / `assistant.js`, which were not read.
- **Export seed → fixture picker:** `exportSeed` selects `d.slug` in `#fixtureSelect` (`:2036`). Whether a seed-only fixture (no bootstrap) is even listed by `/api/annotation/fixtures` (`diagnostics.py:239`) was not read, so the auto-select may silently do nothing.
- **Score grounding with extras missing:** server behaviour when `[eval-grounding]` is absent but a seed exists was not traced.
- **Rendered appearance:** banner legibility over scrolled content, heatmap `#fff`-on-`hsl(… 30%)` contrast (`dashboard.html:118`, `routes.py:331`), and the size of the detail-panel scroll jump were inferred from CSS, not observed in a browser.
- **UX-26** is a code trace, not a reproduction. The mechanism depends on the draft existing when the Score grounding reload fires, which follows from `:2102-2103` (every edit schedules a draft save) but was not exercised.
